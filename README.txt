TOURNAMENT BOOKING - DEMO
เวอร์ชันนี้เป็นเดโมที่ทำงานในเบราว์เซอร์โดยใช้ localStorage
มีหน้าสมัคร, จำนวนทีม, แนบสลิป, และหน้า Admin เบื้องต้น

สำคัญ:
- ยังไม่เหมาะกับการรับเงินจริงหรือใช้งานหลายเครื่อง
- localStorage ทำให้ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์
- ก่อนเปิดใช้งานจริงควรเชื่อม Supabase เพื่อให้ข้อมูลและสลิปอยู่บนฐานข้อมูลกลาง
- หน้า Admin ในเดโมนี้เป็นเพียงต้นแบบ ไม่ใช่ระบบความปลอดภัยจริง

ไฟล์:
index.html = หน้าสมัคร
admin.html = หน้า Admin
app.js = ระบบสมัคร
admin.js = ระบบ Admin
style.css = ดีไซน์
